# Mini E-Commerce Store

A simple junior-level e-commerce project built with HTML, CSS and JavaScript.

## Features

- Product catalog
- Product cards with price and category
- Search products
- Add to cart
- Update cart quantities
- Remove products from cart
- Automatic subtotal calculation
- Checkout form
- Order confirmation

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage

## Project Goal

Practice real-world front-end development concepts such as DOM manipulation, state management, cart logic, form handling, responsive UI and browser storage.
